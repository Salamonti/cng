    Note Type Settings¶

    You can customize which note types appear in the workspace and which one is selected by default when you start a new encounter.

    Setting a Default Note Type¶

    When you create a new encounter, the note type dropdown defaults to a specific type. You can change this:

    1. Open Settings (gear icon in the tools sidebar).
    2. Find the Default Note Type option.
    3. Select your preferred note type from the dropdown (e.g., "Follow-up Note", "Consultation Note", "SOAP").
    4. Settings are saved automatically.

    The next time you create a new encounter, your chosen note type will be pre-selected.

    Hiding or Showing Note Types¶

    If you don't use certain note types, you can hide them to keep the dropdown clean. Conversely, you can show note types that were previously hidden.

    1. Open Settings.
    2. Find the Note Type Visibility section.
    3. You'll see a list of all available note types with toggles.
    4. Toggle off note types you don't use to hide them.
    5. Toggle on note types you want to see.

    Hidden note types are not deleted — they can be re-enabled at any time.

    Why Customize?¶

    • Reduce clutter: Hide note types you never use to keep the dropdown focused.
    • Speed up workflow: Set your most-used note type as default to save a click.
    • Team consistency: If multiple clinicians share a setup, standardize on the note types your team uses.
