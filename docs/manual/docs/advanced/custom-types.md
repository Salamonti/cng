# Custom Note Types

DreamCision comes with 10 built-in note types. If you need a different format, you can create your own.

---

## When to Create a Custom Type

Create a custom note type if you regularly produce notes that don't fit the standard types — for example:

- "Operative Report"
- "Pre-op Assessment"
- "Fitness to Work Certificate"
- "Medical Letter of Medical Necessity"

---

## Adding a Custom Note Type

1. Open **AI Prompts** (⚙️ in the left sidebar)
2. Switch to the **Note Types** tab
3. Click **"Show add custom note type"**
4. Enter a **name** for your new type
5. Optionally enter an **initial template** (you can edit this later)
6. Click **Add type**

### Using the Template Library

You can also click **"Browse template library..."** to open a catalog of pre-made templates. Pick one to pre-fill the name and template, then edit as needed before adding.

---

## Renaming a Custom Type

1. Select the custom type from the dropdown
2. In the Note Types tab, enter the new name in the rename field
3. Click **Rename**

Built-in note types cannot be renamed.

---

## Deleting a Custom Type

1. Select the custom type from the dropdown
2. In the Note Types tab, click **"Delete selected custom type"**

This only removes the type — it does not affect any notes already generated with it.
