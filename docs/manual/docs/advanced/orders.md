# Order & Referral Requests

After generating a note, DreamCision can automatically identify any orders or referral requests mentioned in your dictation and present them as individual, copyable items.

---

## How It Works

1. Generate your note
2. If orders or referrals were detected, an **"Order & Referral Requests"** button appears
3. Click it to open the requests panel

![Order Requests button](../images/order_requests_button.png)

---

## The Requests Panel

Each detected request appears as a separate card that you can:

- **Review** — read the full request
- **Edit** — modify the text if needed
- **Copy** — copy individual requests to paste into ordering systems

If no requests were detected, you will see "No requests were detected."

---

## Retry

If you think requests were missed, click **Retry** to run the extraction again.
