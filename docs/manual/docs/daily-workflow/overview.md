# Daily Workflow Overview

Here is the typical flow for a patient encounter, from start to finish:

```
1. Start a new encounter
2. Press Record and speak
3. Add any chart data (labs, imaging, prior visits)
4. Select note type
5. Press Generate
6. Review and edit the note
7. Copy to your EMR or Word
```

Each step is covered in detail on the pages below.

---

## Quick Start (5 Minutes)

If you just want to get going:

1. Press the **Record** button (🎙️)
2. Speak naturally about the patient encounter
3. Press **Record** again to stop
4. Your transcription appears in the Current Encounter section
5. Select a **Note Type** from the dropdown
6. Click **Generate**
7. Review the note, make any edits
8. Click **Copy Note** and paste into your EMR

That's it. The pages below explain each step in detail.
