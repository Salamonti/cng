# Note Types — At a Glance

| Note Type | When to Use | Structure |
|-----------|------------|-----------|
| **Consultation Note** | New patient, specialist opinion | HPI, Exam, Assessment, Plan |
| **Follow-up Note** | Return visit, monitoring | Updated HPI, Interval changes, Plan |
| **Referral Letter** | Sending patient to specialist | Reason for referral, Summary, Request |
| **Admission Note** | Hospital admission | Full HPI, PMH, Meds, Exam, Plan |
| **Progress Note / SOAP** | Routine documentation | Subjective, Objective, Assessment, Plan |
| **Discharge Summary** | End of hospital stay | Course, Outcome, Discharge plan, Meds |
| **Transfer Note** | Moving between facilities | Reason for transfer, Status, Recommendations |
| **Procedure Note** | Documenting a procedure | Indication, Procedure, Findings, Complications |
| **Summarize** | Condensing long chart data | Executive summary of key points |
| **Custom (Free Form)** | Anything else | Follows your custom prompt template |
