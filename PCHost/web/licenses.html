Node (PCHost proxy)

The default PCHost stack uses Express, cors, and http-proxy-middleware — typically MIT License. The package metadata in PCHost/package.json is MIT. Run npm ls in the PCHost folder for your exact dependency tree.

Frontend

DreamCision web pages use standards-based HTML, CSS, and JavaScript served by PCHost. No React/Vue bundle is required for the default UI. Third-party snippets may be embedded; refer to the repository for any inline libraries.
