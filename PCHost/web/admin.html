▼ Server Configuration

Admin API defaults to /api. Override via localStorage admin_config.apiBase if needed.

Open clinical app

Clinical app — config.json

Read/write Clinical-Note-Generator/config/config.json. JWT and API keys are shown as __REDACTED__ until you replace them; saving keeps on-disk secrets when those placeholders are unchanged. Post-save validation rejects empty or clearly truncated JSON. Changing auth secrets usually requires restarting the FastAPI process; other keys may hot-reload where supported (see runbook).

Single source of truth: service_endpoints.json

Edit endpoints, ports, and per-service llama-server profiles here. Saving updates the file on disk; restart affected services to apply.

LLM / Whisper instances (structured form)

Use Form ← JSON after editing the file, adjust models and sampler fields, then JSON ← form before save. Browse… opens the server file explorer; models ▸ llama / models ▸ whisper jump to the first matching models/<folder> under the checkout. Default note/QA temperatures and related keys also live in Server Configuration → Clinical app — config.json above. Refresh AI status probes listening ports only — it does not start or stop servers. Run llama-server and whisper-server yourself (or NSSM). Saving JSON still writes service_endpoints.json; restart those processes to apply changes.

Whisper (ASR) instances
Feature routing

Maps each workload to a llama_instances id (primary / optional fallback). Saving runs the same sync_env_from_structure step as the JSON editor — env.NOTEGEN_*, LLM_*, OCR_*, etc. Use Form ← JSON after editing raw JSON, then JSON ← form before save.

Office stack (Node, FastAPI, RAG) is configured in office_stack_processes / office_stack_order in service_endpoints.json and started via NSSM (e.g. startup/start-office-stack.ps1). Use the Service Management table above for Windows/NSSM lifecycle — this section avoids duplicating those controls.
